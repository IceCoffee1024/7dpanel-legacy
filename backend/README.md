# 7DPanel Backend

The private core backend for 7DPanel. It will run as a Mod DLL inside the 7DTD
Dedicated Server Mono process.

```text
src/      Mod DLL and embedded Web API implementation
tests/    Backend unit and integration tests
```

The project has not been initialized. The root `docs/` directory owns the
product contract, system architecture, and cross-system release gates. This
directory owns the backend implementation and its direct tests.
