# 7DPanel Admin

The web administration interface for 7DPanel.

Only the application boundary exists today; the frontend project has not been
initialized. The root `docs/` directory owns the product scope, interface
design, and cross-system test contract. This directory owns the admin
implementation and its direct tests.

```text
src/      Frontend implementation
tests/    Frontend unit and component tests
```

The framework, package manager, build commands, and open-source license have not
been selected. Do not add placeholder commands or claim a license before those
decisions are made.
