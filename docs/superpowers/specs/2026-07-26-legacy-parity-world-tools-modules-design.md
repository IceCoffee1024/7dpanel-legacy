# 旧版本功能对齐第六波：世界工具、地图作业与功能模块设计规格

## 上游、状态与波次职责

本规格落实[产品需求](../../PRD.md) `CAP-02`、`CAP-05`、`CAP-12`、`NFR-02`、`NFR-03`、`NFR-04` 与 `NFR-05`，复用[玩家坐标地图设计规格](2026-07-26-player-coordinate-map-design.md)的只读地图和[地图管理操作设计规格](2026-07-26-map-management-actions-design.md)的领地删除、玩家传送与地图渲染边界，并消费第二波持久作业。当前事实仍以[系统架构](../../architecture.md)为准。

这是六波次规格集的最后一波。它逐项类型化旧版高风险世界操作，并在所有真实能力已经存在后提供功能模块状态页；不创建通用世界脚本、万能 action payload 或运行时插件框架。

## 用户结果

- `Owner` 可以在地图和详情页查看领地、载具、无人机及批准容器信息，并明确每项数据的观察时间和完整性。
- `Owner` 可以通过固定目标确认执行领地删除、玩家/实体移动、地图资源刷新/渲染、区域复制/填充、Prefab、方块、实体、撤销、XML reload 和 GC 等批准工具。
- 长时间作业可在刷新或重启后恢复状态；排队、运行、结果未知和回滚失败不会显示为成功。
- 功能模块页显示每项能力的启停、依赖、设置摘要和停用影响，停用不会自动删除业务数据或留下无人处理的任务。

## 世界只读模型补齐

现有地图图层继续是只读入口。SevenDays Adapter 在游戏线程复制以下标量快照：

- 领地：服务端 ID、所有者稳定身份、中心/范围、有效性和最近登录；
- 载具与无人机：实体 ID、类型、所有者、位置、加载/锁定状态、燃油/品质和批准容器摘要；
- 容器：稳定父对象、槽位数量、已用数量和可选物品摘要；
- 世界与地图资源：世界 ID、seed/尺寸、游戏版本、地图资源版本、可用范围和观察时间。

HTTP 不返回游戏对象、存档路径、磁盘目录或可写文件名。一个来源失败只影响对应图层/详情；未知字段保持 `null`。容器详情只读，不能从过期 snapshot 发起删除或移动。

## 持久世界操作

所有写操作先创建独立类型化 operation，保存操作者、操作类型、规范目标、世界/资源版本、确认摘要、时间、状态和 correlation ID。operation 复用第二波作业生命周期，但每类参数和状态验证由自己的 Application 用例拥有。

通用状态为 `Queued`、`Running`、`Succeeded`、`Failed`、`Cancelled`、`Interrupted`、`ResultUnknown` 和适用的 `RollbackFailed`。排队前持久化审计意图；无法持久化时不执行。游戏副作用在 `GameThreadDispatcher` 内完成，文件/压缩/渲染在有界后台 worker 完成；两者之间只传不可变标量和服务端受控资源 ID。

## 地图与实体操作

### 已批准地图动作

领地删除、在线玩家传送、服务端瓦片资源刷新、已探索区域渲染和完整地图渲染沿用现有独立设计。提交后服务端重新验证领地/玩家/世界和地图资源版本；浏览器 tile source 重载仍是纯客户端行为，不能触发服务端作业。

地图输出写入服务端临时根，完成范围、manifest、尺寸和文件安全校验后原子提升 `mapResourceVersion`。失败保留上一版本。完整渲染使用强确认且同一世界互斥。

### 载具、无人机与实体移动

移动请求固定实体 ID、类型、所有者/稳定身份、来源观察、目标世界坐标和目标资源版本。执行前必须重新确认同一实体和世界；实体消失、ID 复用、类型变化或目标越界时拒绝。不能拖拽松手即提交，必须显示固定摘要并确认。

删除实体与移动实体分离，不允许一个 `mode` 字段切换危险含义。容器物品不随意改写；目标游戏 API 无法证明容器一致性时仅提供只读摘要。

## 区域、方块与 Prefab 工具

### 区域复制与填充

请求使用服务端验证的世界 ID、两个坐标或批准形状、固定操作类型、方块/资源选择和范围上限。复制输出保存为服务端生成的临时 change set；填充、清空和粘贴分别是独立用例。超出体积、跨世界、未加载区域或游戏状态不允许时在副作用前拒绝。

长区域操作分批进入游戏线程，单批有帧预算和可观察进度；后台 worker 不访问 Unity/7DTD 活对象。部分完成时记录已应用范围和 `ResultUnknown`/失败，不能把整项表示为成功。

### 方块与 Prefab

方块设置只接受当前资源目录中批准的 block internal name、旋转/形态白名单和精确坐标。Prefab 操作只接受服务端目录中的不透明 prefab ID、批准旋转和边界；浏览器不能提交 XML、文件名或路径。

Prefab 放置、删除和重载分别定义。实施前保存可恢复 change set；无法生成回滚证据的范围使用更强确认并标明不可自动撤销。

### 实体维护、reload 与 GC

实体生成、删除或清理只接受固定实体类型目录、数量/范围上限和当前世界；不接收控制台原文。XML reload 按批准资源类型拆分，不允许任意文件 reload。GC 是独立 Owner-only 操作，只请求受控游戏 GC/资源回收入口，并返回已接受、完成或结果未知，不宣称改善性能。

## 撤销与恢复

撤销只作用于 7DPanel 自己产生且仍与当前世界版本兼容的 change set。每个 change set 有来源 operation、范围、前/后摘要、哈希、创建时间和保留期；一次成功撤销产生新的 operation，不能删除原记录。

世界版本变化、目标范围已被第三方修改、change set 损坏或超期时拒绝自动撤销。中断恢复优先保留可解释状态和旧地图/世界证据，不尝试未经验证的自动猜测修复。

## 功能模块

模块目录是编译期关闭集合，只为已经实现的真实能力提供条目：概览、玩家历史/地图、控制台、聊天、游戏资源、备份、公告/调度、玩家物品、经济/奖励、传送/投票、自动化、Discord、GeoIP 和世界工具。每项声明：

- 当前启停、依赖、配置摘要和健康状态；
- 停用是否立即生效、需排空还是需重启；
- 停用后保留的数据、仍可读取的历史和禁止的新动作；
- 依赖模块、运行作业和阻止停用的原因。

模块页不扫描程序集、不动态加载代码，也不替代服务器 Mods 管理。停用有运行任务的模块时，服务端安全拒绝或进入批准的 draining；不得自动取消结果未知动作或删除数据。重新启用恢复配置，但不自动重放停用期间事件。

每个模块显式声明 `isToggleable`。身份、授权、审计、运行时健康和依赖它们的核心基础模块不可停用；概览等入口只有在其依赖和最低可管理状态仍成立时才允许切换。服务端拒绝客户端把受保护模块改为可切换。

## 接口与 Admin

- `/api/v1/world/*`：领地、载具、无人机、容器和服务端资源目录的只读查询。
- `/api/v1/world-operations/*`：每类危险操作独立 POST 与 operation 查询。
- `/api/v1/map-jobs/*`：地图资源刷新/渲染和版本读取。
- `/api/v1/modules`：模块摘要、依赖和独立启停命令。

只读 popup 与操作面板分离。危险确认持续显示目标、世界、范围、资源版本、可撤销性和预计影响；完整渲染、大区域、Prefab、批量实体和不可撤销动作使用强确认。页面刷新后按 operation ID 恢复，不把 HTTP 202 显示为终态。

## 权限、安全与资源限制

- 所有世界写操作和模块切换仅 `Owner`；只读图层沿用现有授权。
- 浏览器不得提交文件路径、XML、脚本、任意命令、任意类型名或通用序列化 payload。
- 每类操作定义坐标、范围、数量、时间、队列容量和单帧预算；不同世界/类型的并发必须由真实负载证据批准。
- 审计摘要不包含路径、完整容器内容或原始异常；敏感玩家/世界字段继续服务端裁剪。

## 非目标

- 不提供通用世界脚本 IDE、任意 Harmony 调用、任意反射、任意文件编辑或任意控制台包装器。
- 不支持跨服世界复制、在线上传 Prefab、模组热加载或第三方插件市场。
- 不把模块页实现为新的 DI registry；模块集合来自已经存在的明确消费者。
- 不保证旧版每个低价值工具的 UI/路由兼容，只保证批准用户结果、参数约束和失败行为。

## 精简验证

- 世界字段复制、空值、版本、身份和不可变性测试。
- 每类 operation 的固定目标、范围、状态机、幂等、取消、关服、重启和审计测试。
- 临时目录、地图原子发布、change set/hash、路径穿越、reparse、损坏与撤销冲突测试。
- Dispatcher 分批、队列容量、帧预算替身和异常隔离测试。
- HTTP/OpenAPI 独立 DTO、Owner-only、确认、202/operation 和错误脱敏测试。
- Admin 只读/写边界、强确认、状态恢复、模块依赖、双语和窄屏聚焦测试。
- 每类真实游戏 API 只进行一个最小 smoke；删除、填充、Prefab、实体和撤销只使用可丢弃测试世界并保留前置备份。

## 完成条件

- 旧版主要世界读模型与批准写工具均有类型化入口、服务端限制、权威状态和审计。
- 地图/世界长作业在刷新、失败、关服和重启后保持可查询，失败不覆盖最后有效资源。
- 撤销只作用于 7DPanel 自有且可验证的 change set，不承诺无法证明的恢复。
- 功能模块只管理真实能力和依赖，不动态加载代码、不删除数据、不留下无人处理作业。
- `CAP-01` 至 `CAP-12` 的主要能力全部实现或具有用户批准的替代行为后，才允许进入旧版主要功能对齐的最终发布门禁。
